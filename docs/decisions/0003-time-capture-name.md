# 0003: Adopt Aleatory Time Capture as the service name

- Status: Accepted
- Date: 2026-10-02
- Owners: Founder

## Context

The project began under the working name **Aleatory Spatial Memories**. The
founder reevaluated the brand architecture to make the relationship between the
company, project, and product line clearer.

## Decision

Use **Aleatory Time Capture** as the service and project name. **Aleatory** is
the underlying company, **Time Capture** is the descriptive name of this
project, and **Remembering Presence** remains its customer-facing product line.

Continue using **Spatial Memory** as a plain-language product concept where it
helps explain an explorable spatial record. It is no longer the service brand.
The existing `rememberingpresence.com` domain remains appropriate for the
product line.

## Consequences

- Public wordmarks, metadata, privacy copy, and consent language use Aleatory
  Time Capture.
- Internal documentation and package metadata use the new project name.
- Existing infrastructure hostnames and email addresses remain unchanged.
- The source repository is renamed to match the project.
- Trademark and customer-comprehension review remain future work.
